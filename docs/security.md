# 🔐 Security

РейсКонтроль строится по принципу защиты в глубину.

## Backend

- проверка авторизации;
- проверка ролей;
- защита API;
- audit событий.

## Database

- PostgreSQL;
- Row-Level Security;
- разделение доступа к данным.

## Storage

- закрытое файловое хранилище;
- отсутствие публичного доступа к документам по умолчанию.

## Infrastructure

- reverse proxy;
- Docker;
- secrets вне исходного кода;
- отдельные проверки перед релизом.

## Android

Разрешения приложения минимизируются и выдаются только для реально используемых функций.
