# 🖥 Web Platform

Web-платформа предназначена прежде всего для логиста и управления операционными данными.

## Стек

- Next.js;
- TypeScript;
- Tailwind CSS;
- Spring Boot;
- PostgreSQL;
- Docker Compose.

## Основные сущности

- рейсы;
- клиенты;
- водители;
- автомобили;
- прицепы;
- документы;
- назначения.

## Backend

REST API работает под `/api/v1`.

Health endpoint используется для проверки состояния backend.

## Geo

Для геокодирования и расчёта расстояний используются Nominatim и OSRM.
