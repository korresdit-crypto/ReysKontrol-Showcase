# 📱 Mobile App

Android-приложение предназначено для работы с рейсами непосредственно с мобильного устройства.

## Основные сценарии

- создание нового рейса;
- просмотр текущих рейсов;
- ввод расходов;
- расчёт итогов;
- работа с документами;
- OCR заявки;
- экспорт данных;
- работа с ролью водителя.

## Технологии

- Java;
- Android;
- Room;
- JUnit;
- Tesseract OCR.

## UX

Проект постепенно переводит длинные формы в более пошаговые сценарии, чтобы ввод данных в рейсе был быстрее и понятнее.
