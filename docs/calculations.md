# 💰 Calculations

РейсКонтроль включает расчёт операционных и финансовых показателей рейса.

## Учитываемые данные

- ставка;
- расходы;
- суточные;
- простои;
- дополнительные операции;
- расстояние;
- выплаты водителю;
- итоговые показатели.

## Дополнительные операции

Для тентов / штор могут учитываться:

- один бок;
- два бока;
- задняя выгрузка;
- верхняя выгрузка.

## Развитие

Формулы будут расширяться для:

- малотоннажного транспорта;
- самосвалов;
- тягачей с самосвальным полуприцепом;
- различных схем оплаты водителей.
