# 🗺 Roadmap

РейсКонтроль продолжает развиваться.

## Направления

- расширение web-кабинета;
- редактирование и удаление сущностей;
- редактирование созданных рейсов;
- улучшение автоматического расчёта расстояния;
- развитие синхронизации Android ↔ Web;
- работа с документами;
- новые типы транспорта;
- дополнительные формулы зарплаты;
- улучшение UX;
- дальнейшее усиление security.
