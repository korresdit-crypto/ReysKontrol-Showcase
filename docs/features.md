# 🧩 Features

## Рейсы

- создание рейса;
- адреса погрузки и выгрузки;
- даты;
- груз;
- ставка;
- расстояние;
- расходы;
- итоговые показатели.

## Транспорт

Поддерживаются разные типы грузового транспорта и прицепов.

Система развивается в сторону поддержки:

- тягачей;
- малотоннажного транспорта;
- самосвалов;
- самосвальных полуприцепов;
- рефрижераторов;
- контейнеровозов;
- тентов / штор.

## Документы

- проверка заполненности.
