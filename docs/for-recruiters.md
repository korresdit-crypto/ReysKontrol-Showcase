# 👔 For Recruiters

РейсКонтроль — мой практический Android + Web проект в сфере грузоперевозок.

## Что он демонстрирует

- Android development;
- Java;
- REST API;
- Spring Boot;
- PostgreSQL;
- Docker;
- Next.js;
- тестирование;
- OCR;
- role-based access;
- security-first архитектуру;
- работу с реальной предметной областью.

## Практика QA

В проекте используются unit, connected, migration, lint, security и regression проверки.

## Важно

Публичный Showcase не содержит основной private codebase, credentials и реальные пользовательские данные.
