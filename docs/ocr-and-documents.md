# 📄 OCR & Documents

В проекте используется OCR для ускорения переноса данных из заявок и документов.

## OCR

Текущая логика ориентирована на распознавание:

- адресов;
- дат;
- груза;
- веса;
- ставки;
- компании;
- ИНН;
- контакта;
- телефона;
- комментариев.

Используется Tesseract с русским и английским языками.

## Принцип

Парсер не должен выдумывать отсутствующие данные.

Особенно важно не угадывать города и другие критические поля при низкой уверенности распознавания.

## Export

Проект поддерживает экспорт данных в файлы, включая CSV/PDF сценарии.
