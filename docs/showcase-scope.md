# 🪟 Showcase Scope

Этот репозиторий является публичной витриной РейсКонтроля.

## Публикуется

- архитектура;
- функции;
- технический стек;
- QA-подход;
- security-принципы;
- обезличенные screenshots;
- roadmap.

## Не публикуется

- основной source repository;
- API keys;
- `.env`;
- реальные пользовательские данные;
- production credentials;
- приватные документы;
- production database;
- внутренняя конфигурация.

Цель Showcase — показать инженерную работу над проектом без раскрытия чувствительных данных.
